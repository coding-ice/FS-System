按主题选用，不要机械保留所有标题。

````markdown
# {{主题}}

一句话：{{它解决的问题 + 适用时机}}

## 先记住这几点

- {{结论 1}}
- {{结论 2}}
- {{结论 3}}

## 它如何工作

```mermaid
{{仅在关系、状态或步骤需要可视化时绘制}}
```

## 关键代码

```{{语言}}
{{只保留一个核心 API 或机制所需的最小片段}}
```

{{解释：输入是什么、关键调用是什么、会产生什么可观察结果。}}

## 容易踩坑

- {{误区或边界}}

## 自己练一练

1. {{练习目标}}：{{验收条件}}

## 参考

- [{{官方资料}}]({{直接链接}})
```
````

## 压缩规则

- 每个代码片段只回答一个问题；长示例只保留能解释 API 的部分。
- 图表只展示正文不易线性说明的关系，不重复文字。
- 练习描述任务和验收条件，不附完整答案，除非学习者明确索要。
- 把版本、前提条件和不保证的行为写在相应结论旁边。
